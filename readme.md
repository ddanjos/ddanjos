### // 01 · origem

```bat
@echo off
title davidy.anjos
:: o primeiro script. o resto é consequência.
echo Ola, mundo.
pause
```

Foi num arquivo `.bat` que percebi que dá para mandar a máquina trabalhar por mim.
Desde então, a pergunta é sempre a mesma: **qual é a forma mais simples de resolver isso de verdade?**
